# 📊 StatBot – Jarvis-Style Statistical Assistant

StatBot is a Flask-based AI-powered chatbot and analysis tool designed to answer statistical questions, perform data analysis, and provide visualizations. It includes a voice output system inspired by Jarvis.

## 🚀 Features
- Ask natural language statistical questions (e.g., "What is the Central Limit Theorem?")
- Upload CSV/Excel files for analysis
- Run statistical tests: T-tests, ANOVA, Chi-square, etc.
- Generate visualizations: Box plots, Heatmaps, Pie charts, etc.
- Voice feedback via TTS using `pyttsx3`
